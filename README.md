# Programa de Dactilografía

Proyecto web estático de práctica de mecanografía con enfoque en legal y administrativo.

## Qué incluye

- Práctica con temporizador configurable
- Lecciones por nivel
- Exámenes simulados
- Seguimiento de velocidad, precisión y errores
- Teclado visual con indicadores de dedos
- Elementos gráficos y tema oscuro

## Cómo abrirlo

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. También puedes servir la carpeta con un servidor local si prefieres.

## Tecnologías

- HTML
- CSS
- JavaScript
